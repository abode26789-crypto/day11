# AI Chatbot App 🤖

A simple AI chatbot application built with **Flutter**.
The app allows users to interact with an AI assistant through a clean and simple chat interface.

## Features

* 💬 Real-time chat with AI
* 🤖 AI-powered responses
* 🎨 Simple and user-friendly interface
* 📱 Responsive Flutter UI
* 🔄 Send and receive messages easily

## Technologies

* Flutter
* Dart
* AI API
* REST API

## Purpose

This project was created to learn and practice **Flutter app development, API integration, and AI chatbot functionality**.
